# Task 2 – Defect Detection

This folder contains the source code for the Defect Detection task completed during the Algonive ML Internship.

**Files included:**
- `prepare_dataset.py` – Prepares and processes the dataset.
- `train_classification_model.py` – Trains the CNN model for defect detection.
- `evaluate_model.py` – Evaluates the model performance and generates summary results.

⚠️ Dataset is not uploaded due to GitHub file size limits. It is stored locally.
